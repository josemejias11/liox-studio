# TASK-0014: Redesign disclaimer — three-field layout (title / body / numbered disclaimers)

## Goal
Replace the current single-PortableText disclaimer design with three distinct fields: a `title`, a plain-text `body` intro paragraph, and a new `disclaimers` array rendered as a numbered list — and wire all three through the Sanity schema, Zod contract, GROQ query, and `DisclaimerPage` component.

## Context
The disclaimer currently has one rich-text `body` field (PortableText) that tries to carry both an intro paragraph and the numbered items. Content editors need the three areas separated so each can be authored independently: a short intro (`body`) and a dedicated numbered-bullet list (`disclaimers`). This is a deliberate schema redesign — existing PortableText `body` content will need to be re-entered as plain text after the migration; that is acceptable.

## Affected Area
- Layer: frontend + Sanity schema (cross-cutting)
- Agent role: web-engineer

### Patterns in use
- `opt()` helper in `sanity.ts` wraps any nullable Zod type: `opt(z.array(z.string()))`.
- `portableTextSchema` and `richTextSchema` already exist in `sanity.ts` — do not remove them (other fields use them); just stop referencing them from `disclaimerSchema`.
- Sanity `type: 'text'` produces a plain multi-line textarea in Studio; `type: 'string'` is a single line. Use `type: 'text'` for `body` and `type: 'string'` for each item in the `disclaimers` array.
- `defineField` + `defineArrayMember` (`defineArrayMember({ type: 'string' })`) is the typed way to define array item schemas in Sanity v3.
- The `DISCLAIMER_FIELDS` GROQ fragment projects array fields bare (e.g. `disclaimers[]` or just `disclaimers` — either form works for arrays of primitives in GROQ).
- `DisclaimerPage.tsx` uses `framer-motion` `itemVariants` for staggered entry — wrap new sections with `<motion.div variants={itemVariants}>`.
- Tailwind prose classes (`prose prose-sm dark:prose-invert`) are only needed for PortableText; a plain `<p>` should use `text-muted-foreground leading-relaxed` instead.

### Known constraints
- `PortableText` import and `@portabletext/react` can be removed from `DisclaimerPage.tsx` if `body` is now a plain string — remove the dead import to keep lint clean.
- `body` is currently validated `r.required()` in the Sanity schema. Keep it required.
- Do not change `acknowledgementRequired`, `acknowledgementLabel`, `category`, or the `CATEGORY_LABELS` map — those settings fields are correct.
- Do not touch `MotoViewer.tsx` — it passes `disclaimer` straight through; the type change propagates automatically.
- Do not touch `course.ts` schema or `courseSchema` in `sanity.ts` — the `disclaimer` field there is a reference and is unaffected.
- `npm run typecheck` must pass with zero new errors after changes.

## Requirements
1. **Sanity schema** (`disclaimer.ts`): `body` field type changed from `array` (PortableText) to `text` (plain multi-line textarea). A new `disclaimers` field is added after `body` — `type: 'array'`, `of: [defineArrayMember({ type: 'string' })]`, title `'Disclaimers'`, description `'Each entry becomes a numbered item.'`, group `'content'`.
2. **Zod contract** (`sanity.ts`): `disclaimerSchema.body` changed to `z.string().catch('')`. New field `disclaimers: opt(z.array(z.string()))` added to `disclaimerSchema`. `portableTextSchema` import line in this file is **not** removed (used by other schemas).
3. **GROQ query** (`queries.ts`): `DISCLAIMER_FIELDS` fragment includes `disclaimers` (or `disclaimers[]`).
4. **Component** (`DisclaimerPage.tsx`):
   - The PortableText block is replaced with a plain `<p>` rendering `disclaimer.body` using `text-muted-foreground leading-relaxed text-base` classes, wrapped in `<motion.div variants={itemVariants}>`.
   - Below the body paragraph, a new `<motion.div variants={itemVariants}>` section renders `disclaimer.disclaimers` as an `<ol>` with `list-decimal list-outside pl-6 space-y-3` — each `<li>` gets `text-muted-foreground leading-relaxed` — only rendered when the array is non-empty.
   - Dead `PortableText` import and `@portabletext/react` import removed.
5. `npm run typecheck` passes with zero new errors.
