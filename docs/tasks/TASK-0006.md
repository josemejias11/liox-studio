# TASK-0006: Wire course-level quiz to always show the AI quiz

## Goal
The course-level quiz phase always renders the adaptive AI quiz (`CourseQuiz`) with `weakTopics` from learner analytics, falling back to the Sanity-authored quiz only when explicitly configured in the CMS.

## Context
The app has two quiz paths. The **lesson-level** quiz (inside a chapter, `case 'quiz'` in the inner `renderPhase` switch of `MotoViewer.tsx`) already works correctly — it always calls `CourseQuiz` with `weakTopics={buildWeakTopics()}`. The **course-level** quiz (`phase.phase === 'quiz'` in the outer switch) is broken in two ways:
1. Navigation (`useCourseNavigation.ts`) only routes to `phase: 'quiz'` when a `quizSection` record exists in Sanity. No Sanity quiz = quiz phase skipped entirely.
2. The render (`MotoViewer.tsx`) returns `null` when `quizSection` is undefined instead of falling through to the AI quiz.

The result: users always see either the static Sanity quiz or nothing. The AI quiz (`CourseQuiz` — Brain icon, emerald color, "Adaptive AI Quiz" header, Sparkles button, weakTopics feedback badges) is never shown at the course level.
