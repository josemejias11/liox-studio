# TASK-0003: Harden parser-service startup against port-typo failures

**Status:** todo

## Goal
Ensure the parser service always starts on port 8000 without requiring the operator to remember the exact uvicorn flags — and add an early-exit guard that surfaces a clear error if a port < 1024 is attempted.

## Context
Running `uvicorn main:app --reload --port 800` (one digit short of 8000) silently attempts to bind a privileged port and dies with `[Errno 13] Permission denied` after the FastAPI lifespan hook has already run. The `__main__` block hardcodes 8000, but CLAUDE.md's recommended command (`uvicorn main:app --reload`) accepts any `--port` flag, leaving the operator exposed to this class of typo. There is no script-level guard and no shell runbook entry that encapsulates the correct invocation.

## Affected Area
- Layer: infra (parser-service startup)
- Agent role: api-services-engineer (Python/FastAPI side)

### Known constraints
- The service binds to `127.0.0.1` only (internal). Do not change the bind host.
- `PORT` env var, if introduced, must default to `8000` so existing `web/.env.local` (`PARSER_SERVICE_URL="http://localhost:8000"`) continues to work with zero changes.
- Do not change any public API surface (`main.py` endpoints, request/response shapes).

## Requirements

1. **`run.sh` startup script** — create `parser-service/run.sh` (executable) that runs:
   ```bash
   uvicorn main:app --host 127.0.0.1 --port 8000 --reload
   ```
   Guard: if `$PORT` is set in the environment and is less than 1024, print a clear error message to stderr and exit 1 before launching uvicorn.

2. **`__main__` reads `PORT` env var** — update the `if __name__ == "__main__"` block in `main.py` to read `PORT` from the environment (default `8000`), and apply the same < 1024 guard before calling `uvicorn.run`.

3. **Update `README.md`** — make `python main.py` or `bash run.sh` the single canonical "start the service" command. Retain the raw uvicorn example as a secondary note.

4. **Update `CLAUDE.md`** — change the parser service dev command from `uvicorn main:app --reload` to `python main.py` (or `bash run.sh`) so the documented path always resolves to port 8000 without flags.

5. **No new dependencies** — the guard and the script must use only the stdlib / bash builtins already in the environment.
