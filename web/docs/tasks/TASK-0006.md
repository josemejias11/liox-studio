# TASK-0006: Chapter Quick Check — Schema, GROQ, and data contract

## Goal
Move the Sanity-authored `quiz` reference from course-level to chapter-level, remove `course.quiz` from every layer, and thread `quickCheck?: SanityQuizDoc` through the chapter data contract so the player can access it per chapter.

## Context
The course-level Knowledge Check is now always AI-generated (`CourseQuiz` component) and no longer driven by a Sanity quiz document. The existing `quiz` document type is repurposed as a chapter-level "Quick Check" — an optional 2–3 question mini-quiz the instructor can attach to any chapter, exactly like they attach lessons. This task covers only the data layer: Sanity schema, GROQ query, Zod contracts, and `course-structure.ts`. Navigation and player wiring are separate tasks (TASK-0007, TASK-0008).

## Affected Area
- Layer: API / DB (Sanity schema + data contracts)
- Agent role: api-services-engineer

### Patterns in use
- All Zod schemas use the `opt()` helper for nullable GROQ fields: `const opt = <T>(s: T) => s.nullish().transform(v => v ?? undefined)`.
- GROQ fragments are composed via template literals — add `quickCheck` to the fragment, not inline.
- `course-structure.ts` is pure (no side effects), imported by both MotoViewer and NavMap.
- `deriveCourseStructure` receives the flat `sections` array AND (after this task) the raw chapters array to access `quickCheck`.

### Known constraints
- Do **not** change `quiz.ts` (the quiz document schema) — it is unchanged and reused at chapter level.
- Do **not** change `QUIZ_GRADING_QUERY` — it is server-only and unaffected.
- `quizOffset` in `CourseStructure` stays — it is used by the progress bar and `getSectionIndex`. Since quiz is no longer a section, `quizOffset = specOffset + specSections.length` will naturally point to the disclaimer index, which is acceptable for progress tracking.
- `disclaimerOffset` computation `= quizOffset + (quizSection ? 1 : 0)` — once `quizSection` is removed, replace with `= quizOffset` (quiz is not a section anymore).
- TASK-0007 and TASK-0008 depend on `ChapterGroup.quickCheck` being present. Write the exact interface as specified in Requirements below.
- `npm run typecheck` must pass with zero errors.
