# TASK-0007: Chapter Quick Check — Navigation state machine

## Goal
Add a `chapter-quiz` phase to `useCourseNavigation` that fires automatically after the last lesson of any chapter that has a `quickCheck`, always advances on both pass and fail, and exposes a `finishChapterQuiz` callback to MotoViewer.

## Context
The course navigation is a pure reducer (`courseNavigationReducer`) over a flat `CoursePhase` discriminated union. Adding chapter-level quick checks requires a new phase `{ phase: 'chapter-quiz'; chapterIndex: number }` injected between "last lesson of chapter N" and "first lesson of chapter N+1" (or post-chapter flow). Quick checks are formative — they always advance regardless of result. This task is purely in `useCourseNavigation.ts`. TASK-0006 adds `quickCheck?: SanityQuizDoc` to `ChapterGroup`; TASK-0008 wires the phase to a React component.

## Affected Area
- Layer: frontend (navigation hook)
- Agent role: web-engineer

### Patterns in use
- All phase transitions go through the pure reducer — no direct `setState` outside the dispatch.
- `forward(next, intro?)` is a local helper in `reduceNext` that returns `{ phase: next, navDirection: 1, showChapterIntro: intro ?? false }`.
- `back(prev)` is the equivalent for `reducePrev`.
- `getSectionIndex` is exported and used by both the progress bar and NavMap — update it for the new phase.
- The hook exports named callbacks (`goNext`, `goPrev`, etc.) created with `useCallback`.

### Known constraints
- `chapter-quiz` always advances — both `onPass` and `onFail` in MotoViewer will call `finishChapterQuiz`. Never block on score.
- `reducePrev` from `chapter-quiz` should go back to the last lesson of that chapter (so back-navigation works naturally).
- `getSectionIndex` for `chapter-quiz` should return the same index as the last lesson of that chapter (it's an in-chapter step, not a top-level section).
- Do not change any other files — all changes are in `useCourseNavigation.ts`.
- `npm run typecheck` must pass with zero errors.
