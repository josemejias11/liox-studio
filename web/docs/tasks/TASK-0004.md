# TASK-0004: Remove double-chrome from in-lesson quiz

## Goal
Wire the in-lesson quiz (`lessonType === 'quiz'`) in `MotoViewer` directly to `CourseQuiz` instead of routing through `QuizLesson`, eliminating the redundant "Knowledge Check" heading that stacks on top of `CourseQuiz`'s own "Adaptive AI Quiz" card header.

## Context
`QuizLesson` is a routing shell: if `sanityQuiz` is passed it renders `SanityQuizPlayer` (new design), otherwise it wraps `CourseQuiz` in an extra layout div with a "Knowledge Check" `<h1>` and subtitle. The in-lesson call site in `MotoViewer` never passes `sanityQuiz`, so it always hits the wrapper branch — producing two chrome layers: the outer "Knowledge Check" heading and `CourseQuiz`'s own card header ("Adaptive AI Quiz" + Brain icon). The decision is: in-lesson quizzes always use the old `CourseQuiz` component directly; the `QuizLesson` wrapper is only needed for the end-of-course quiz phase (which does have `sanityQuiz`).
