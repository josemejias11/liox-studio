# TASK-0001: Safe File Consolidation — Theme utilities + small API contracts

## Goal
Merge three pairs of tiny related files into single modules without touching any feature component or lesson type, preserving full expandability of the lesson and contract layers.

## Context
The project has 30+ source files in `src/components/` and `src/lib/`. After auditing every file and its import graph, three merges are safe (no shared responsibility violated, all import sites trivially updated). Everything else should stay separate — lesson-type components each map to a Sanity schema type (adding a new lesson type = adding one file), and the quiz contract is substantive enough to stay alone. This task executes only the safe merges.

## Affected Area
- Layer: frontend + lib (no API route logic changes, no schema changes)
- Agent role: web-engineer

## Codebase Context

### What NOT to merge (and why)

| `ContentLesson`, `VideoLesson`, `ColorSwitcherLesson`, `DragDropLesson`, `ScrollStoryLesson`, `SplitScreenLesson`, `PhotoCardStack` | Each = one Sanity lesson type. New lesson type = new file. Merging creates a fragile mega-switch. |
| `ChapterIntro`, `CourseCover`, `CourseComplete` | Different lifecycle phases, zero shared logic |
| `DisclaimerPage`, `SpecificationPage` | Similar scroll+nav shell but different schemas, different acknowledgement behavior |

| `CompletionBurst` | Used by both `MotoViewer` AND `ProductStage` — can't be inlined |
| `contracts/quiz.ts` | 125 lines, complex server/client split, used by 3 surfaces; stays alone |
| `useFocusTrap.ts` | Used by both `DiscoveryPanel` and `NavMap` — can't be inlined |
| `sanity-image-loader.ts` | Used by 6 components; staying in `lib/` is fine |

### Patterns in use
- All components use named exports (no default exports).
- `'use client'` directive is required for any component using hooks or browser APIs (`ThemeProvider` and `ThemeToggle` both need it in the merged file).
- Contract files use `zod` (`z` import from `'zod'`) — no other runtime deps.
- Import alias `@/` resolves to `src/`.

### Known constraints
- `contracts/quiz.ts` must NOT be touched — grading logic is security-sensitive (server-side answer key).
- Do not change any exported symbol names — downstream consumers import by name.
- Do not modify any API route handler logic — only their import paths change.
- `ThemeToggle` is imported in `NavMap.tsx` (a component file) AND `page.tsx` (a page). Both need updating.
