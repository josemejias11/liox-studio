# TASK-0008: Chapter Quick Check — MotoViewer player integration

## Goal
Wire the new `chapter-quiz` navigation phase into MotoViewer: update `deriveCourseStructure` call to thread chapter `quickCheck` data, change the course-level quiz case to always use `CourseQuizDynamic` (no `sanityQuiz`), and add a `case 'chapter-quiz'` that renders `QuizLesson` with the chapter's `quickCheck`.

## Context
TASK-0006 removes `structure.quizSection` and adds `quickCheck?: SanityQuizDoc` to each `ChapterGroup`. TASK-0007 adds `{ phase: 'chapter-quiz'; chapterIndex: number }` to `CoursePhase` and exposes `finishChapterQuiz(chapterIndex)` from the navigation hook. This task is the final wire-up: `MotoViewer.tsx` is the only file that needs to change. All other logic (routing, structure derivation, navigation state) is already in place after the previous two tasks.

### TypeScript note
After TASK-0007, `CoursePhase` includes `{ phase: 'chapter-quiz'; chapterIndex: number }`. The `renderPhase` switch currently has no `chapter-quiz` case — TypeScript will complain about unreachable code or the switch won't be exhaustive. Adding `case 'chapter-quiz':` fixes this.

### Patterns in use
- All lesson cases in `renderPhase` follow the same `{ slideKey, screen }` return shape.
- Chapter-level quick check renders `QuizLesson` (which routes to `SanityQuizPlayer` when `sanityQuiz` is present).
- Course-level AI quiz renders `CourseQuizDynamic` (already dynamic-imported at line 24).
- `structure.chapters.find(c => c.chapterIndex === phase.chapterIndex)` is the pattern for looking up the current chapter group (used in `showChapterIntro` block at line 285).

### Known constraints
- Chapter quick check always advances on both pass and fail — call `nav.finishChapterQuiz(phase.chapterIndex)` for both callbacks.
- Course-level `case 'quiz'` uses `nav.finishQuiz` (unchanged) for both callbacks.
- `structure.quizSection` no longer exists after TASK-0006 — do not reference it.
- Do not change any other file. All data contract and navigation logic is already wired by TASK-0006 and TASK-0007.
- `npm run typecheck` must pass with zero errors.
